# Whisp 0.4.0

- Configure separate while-recording shortcuts for cancel, paste, and paste-and-Enter, or disable any action
- Assign guarded single presses of Control, Option, Shift, or Command while recording, including single-Control alongside double-Control
- Display physical keys consistently in English regardless of the active keyboard input source
- Keep the floating waveform visible while transcription is in progress, with independent shortcut-hint and status-text toggles
- Preview the recording and transcription overlay safely from Settings without microphone or API use
- Launch Whisp at login through macOS Login Items and restore shortcut listeners after wake or session unlock
- Control automatic update checks, signed update alerts, and background downloads directly from Settings
- Show the animated recording/transcription waveform and app icon in the project README

This build is Sparkle-signed for in-app updates but is not Apple-notarized. On a new installation, macOS may require **System Settings → Privacy & Security → Open Anyway**.
