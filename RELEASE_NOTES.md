# Whisp 0.4.1

- Simplify the app icon by removing the glass-like reflected highlights while preserving the waveform and color palette
- Replace the README animation with an English-language recording and transcription demo
- Prevent passive Keychain reads from opening a macOS password prompt when launching the app or switching providers

This build is Sparkle-signed for in-app updates but is not Apple-notarized. On a new installation, macOS may require **System Settings → Privacy & Security → Open Anyway**.
