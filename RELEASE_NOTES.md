# Whisp 0.3.2

- Browse Vercel AI Gateway speech-to-text models and current pricing directly in Settings
- Choose compatible batch transcription models with a single click
- Clearly identify realtime-only models that are not supported by Whisp's current recording flow
- Keep an instant built-in model list when Vercel's live catalog is unavailable

This build is Sparkle-signed for in-app updates but is not Apple-notarized. On a new installation, macOS may require **System Settings → Privacy & Security → Open Anyway**.
